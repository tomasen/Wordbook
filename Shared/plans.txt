Wordbook explains vocabulary like a patient teacher instead of displaying a dense dictionary entry. Most words use concise, reviewed explanations bundled with the app, including a natural example and an optional memory aid tailored to the word's meaning and spelling, so everyday study works quickly and offline. For an uncommon spelling that is not in the bundled collection, Wordbook asks its service for a reviewed explanation and caches the result on this device; on-device generation is only the final missing-entry fallback. The on-device language model is primarily reserved for an optional spoken-answer mode: speech recognition supplies a transcript, the model compares it with the selected Usage's structured meaning requirements, and a validated mastered result is required before the answer can qualify as GOOD. Wikipedia and web links remain optional ways to explore a word, not sources for the main lesson.
